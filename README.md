# databricks-rag-business-assistant

## Objetivo

Um chatbot que responde perguntas sobre um conjunto de documentos corporativos fictícios.

## Objetivos específicos

- noção de RAG;
- uso de LLM;
- Databricks como plataforma de dados;
- Python;
- preparação/consulta de dados;
- embeddings/vector search;
- arquitetura de uma solução de AI;
- preocupação com segurança, avaliação e limitações.
